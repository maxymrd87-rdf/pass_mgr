# Отчет по проекту «Менеджер паролей»

## 1. Цели и задачи
- Разработать инструмент для создания паролей, устойчивых к брутфорсу и атакам по словарям.
- Внедрить объективную систему оценки надежности пароля.
- Спроектировать модульную архитектуру по стандартам PEP 8 (разделение интерфейса, вычислений и хранилища).

## 2. Реализация (Архитектура модулей)
- **`generator.py`**: Отвечает за вычисления. Использует криптографически безопасный алгоритм (`secrets.SystemRandom`), защищенный от смещения по модулю (modulo bias).
- **`checker.py`**: Аналитический модуль. Вместо примитивного "подсчета баллов", вычисляет энтропию по Шеннону по формуле `E = L * log2(N)`.
- **`storage.py`**: Модуль хранения. Реализует структуру данных в формате JSON с фиксацией времени создания записи.
- **`main.py` / `gui.py`**: Модули пользовательского интерфейса (консольный и графический).

## 3. Рефлексия и вопросы на консультацию
Проект выполнен в полном объеме, поставленные задачи решены. Вопросы для дальнейшего развития (на консультацию):
1. Интеграция шифрования хранилища (AES) с помощью библиотеки `cryptography` для защиты файла `passwords.json` на диске.
2. Безопасная очистка буфера обмена операционной системы после копирования сгенерированного пароля (защита от утечек через буфер).
