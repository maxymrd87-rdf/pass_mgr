# Менеджер паролей

Надежная утилита для генерации криптостойких паролей, математической оценки их надежности (энтропия Шеннона) и локального хранения.

## Основной функционал
1. **Генерация:** Использование модуля `secrets` для защиты от предсказуемости (в отличие от стандартного `random`).
2. **Анализ:** Оценка стойкости с вычислением битов энтропии по длине и мощности алфавита.
3. **Хранение:** Автоматическое сохранение сгенерированных связок "сервис-пароль" в локальный файл `passwords.json`.

## Инструкция по запуску
Проект написан на стандартной библиотеке Python, сторонние зависимости не требуются.

1. Склонируйте репозиторий на свой компьютер:
   `git clone <вставь_сюда_ссылку_на_свой_репозиторий>`
2. Перейдите в папку проекта.
3. Запустите консольную версию (CLI):
   `python main.py`
4. Для запуска графической оболочки (GUI):
   `python gui.py`
